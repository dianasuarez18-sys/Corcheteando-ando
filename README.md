## 🛠️ Tecnologías utilizadas
- HTML5 semántico
- CSS3 con Custom Properties (Design Tokens)
- JavaScript ES6+ puro (sin frameworks)
- Google AI Studio / Gemini (generación de código y copy)

---

## 📋 Metodología de desarrollo (5 fases)
1. **Planificación** — Definición del producto, público objetivo y estructura de la landing page
2. **Generación** — Creación del código base con Google AI Studio y Gemini
3. **Refinamiento** — Auditoría, corrección y mejora del código generado
4. **Integración** — Implementación de persistencia, snippets y sistema de componentes
5. **Optimización** — Ajuste de rendimiento, responsive y despliegue en GitHub Pages

---

## ⚙️ Personalización
1. Clona el repositorio
2. Edita los **design tokens** en `:root` dentro del archivo `index.html`
3. Reemplaza los textos y colores según tu marca
4. Sube los cambios con `git push`
